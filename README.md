## 🤖 IBM Bob Technology Usage

### Overview

IBM Bob was used as an AI-assisted development technology throughout the development of SafeCheck AI. It supported the development process including project planning, coding, debugging, testing, UI refinement, and deployment preparation.

### How IBM Bob Was Used

#### 1. Project Planning & Architecture

IBM Bob helped break the project into manageable modules and organize the application workflow.

The major modules include:

- AI Scam Message Scanner
- URL Safety Checker
- Cybersecurity Awareness Quiz
- Cybersecurity Awareness Hub

#### 2. Frontend Development

IBM Bob assisted in developing and refining the user interface using:

- Next.js
- React
- TypeScript
- Tailwind CSS

It helped with components such as the navigation bar, scanner interface, risk-result cards, quiz interface, and awareness sections.

#### 3. AI Integration

IBM Bob assisted with implementing the API workflow connecting the application with the Grok/xAI API.

The workflow is:

**User Message → Next.js API → Grok/xAI Analysis → Risk Assessment → Result Display**

The system provides a risk score, risk level, and explanations of suspicious indicators.

#### 4. URL Safety Checker

IBM Bob assisted in implementing the URL checking functionality, allowing users to submit suspicious URLs and receive a safety assessment.

#### 5. Cybersecurity Awareness Features

IBM Bob helped implement the Cybersecurity Awareness Quiz and Awareness Hub to educate users about common cyber threats, phishing, suspicious links, impersonation, and social engineering.

#### 6. Debugging & Problem Solving

IBM Bob was used as an AI-assisted debugging tool to identify and resolve issues involving:

- Frontend components
- API routes
- Application logic
- Configuration
- API integration
- UI behavior

#### 7. UI/UX Improvements

IBM Bob assisted in improving the presentation of security results using clear classifications:

- 🟢 Low Risk
- 🟡 Medium Risk
- 🔴 High Risk

This makes cybersecurity results easier for non-technical users to understand.

#### 8. Testing & Refinement

IBM Bob assisted in reviewing and refining the application during development.

Major workflows tested included:

- Scam message analysis
- URL checking
- Cybersecurity quiz
- Awareness Hub navigation
- AI API integration

#### 9. Deployment

The project was maintained using Git and GitHub and deployed using Vercel.

Sensitive API credentials were stored using environment variables and were not included in the public repository.

### Technology Stack

| Technology | Purpose |

### Role of IBM Bob

IBM Bob acted as an AI-assisted development partner throughout the project. It helped transform the initial cybersecurity problem statement into a functional application by supporting planning, implementation, debugging, testing, UI refinement, and deployment.

The result is **SafeCheck AI**, a web-based cybersecurity platform that combines AI-assisted scam detection, URL checking, and cybersecurity awareness education.
